# 提示词库

作曲栏 Git 图标右侧的提示词库。点开后先挑一条提示词，在它的正文页确认，正文才会写进当前输入框，方便再改。它不会发送，也不会写入会话。模型只有在你发出这条输入之后才能看到正文。

同一个弹层和设置页还有「系统尾注」。那一页按当前预设各写一段文字，追加在该预设系统提示词的最后。留空就是不追加。它不写入输入框，也不改预设文件。

个人设置里的「提示词」页和这个弹层改的是同一份库、同一份尾注。

## 使用

图标在 `conversation.input.left`，排在 Git 图标右边。

- 点一行的标题：进入这一条的正文页，标题和完整正文都在这一页，右下角「确认」才写入输入框。写入规则不变：输入框是空的就整段写入，已经有字就插在光标处，不覆盖现有内容；写入后弹层关闭。底部那行小字会写清这次按下去是整段写入还是插在光标处。
- 正文页的「返回」回到列表，「关闭」或 Esc 直接退出，两者都不会写入。写入被拒绝时留在正文页并说明原因。
- 输入框正在处理斜杠命令或发送时不写，弹层里会说明没有写入。
- 点一行右侧的「编辑」后，标题和正文展开在这一条下面，光标落在标题上。新建、删除和保存都在弹层里。
- 弹层打开后光标落在搜索框。未保存的数量按改动的字段数用红字标在保存按钮旁，不是提示词条数。
- 标题超过 200 字或正文超过 100000 字时不发请求，直接说明是标题还是正文超限。
- 弹层和设置页顶部有「提示词」「系统尾注」两页。保存按钮只保存当前这一页。
- 设置 → 个人 → 提示词：同一份列表和正文。保存按钮在面包屑那一行，这一页不能写入输入框。停在「系统尾注」时，这个按钮保存的是尾注。

关掉弹层不会丢掉还没保存的修改，刷新页面会丢掉。保存时如果库刚被另一处改过，会拒绝覆盖，需要重新读取后再存。再次打开弹层或设置页时，如果没有未保存的修改，会静默重读一次库，另一处刚保存的内容就会出现在这里；这次重读失败不报错，屏幕上已有的库保持不变。

## 系统尾注

每个当前预设一张卡片，顺序跟预设列表一致。正文去掉两端空白后追加在该预设系统提示词的最后，位于人设后缀之后。已打开的会话从下一轮模型请求起使用新正文。`{{ }}` 按字面保留，不会当成变量，这样一段写错的花括号不会让这一轮失败。

人设被设成完整提示词的预设（例如官方 `minimal`）会标明「看不到」：那段正文仍可保存，但模型收不到。挂载失败的预设仍可编辑，卡片上写明当前挂不上。

求值时如果查不到预设，这一段变成空，不让这一轮失败。插件卸掉时，这段一起卸掉。

## 存在哪里

Host 在当前 profile 目录读写 `prompt-library.json` 和 `prompt-tails.json`，都不进仓库。浏览器走已登录的 `GET` / `POST /api/prompt.library` 和 `/api/prompt.tails`。两个文件各带整数版本号，保存必须带上打开时的版本号。

没有文件时，对应的库是空的，版本号为 0。文件存在但内容不是一份库时，接口报无法读取，不会把它覆盖成空库。尾注文件无法读取时，系统提示词里也不追加。

一条提示词只有 `id`、`title`、`body`。最多 200 条，标题去掉两端空白后 1–200 字，正文最长 100000 字。`id` 只含字母、数字、下划线和连字符。

一条尾注是预设 id 到正文。正文去掉两端空白后最长 20000 字。空正文不保存。预设 id 只含小写字母、数字和连字符。

## 限制

- 不分组，也不能调整顺序。
- 弹层和设置页共享这一次打开里的未保存修改；真正落盘只发生在保存。
- 有未保存的修改时不重读库，另一处的改动要等到保存撞上版本冲突才发现。
- 替换文件时先写临时文件再改名。Windows 上若目标已存在，会先删掉旧文件再改名，这中间进程退出可能留下临时文件或丢掉这一次写入。提示词库和尾注都是这样。
- 尾注不会出现在把人设设成完整提示词的预设里。

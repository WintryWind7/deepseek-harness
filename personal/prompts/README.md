# 提示词库

作曲栏 Git 图标右侧的提示词库。点开后可以选择已保存的提示词，正文会写进当前输入框，方便再改。它不会发送，也不会写入会话。模型只有在你发出这条输入之后才能看到正文。

个人设置里的「提示词」页和这个弹层改的是同一份库。

## 使用

图标在 `conversation.input.left`，排在 Git 图标右边。

- 点一行的标题：输入框是空的就整段写入；已经有字就插在光标处，不覆盖现有内容。写完后弹层关闭。
- 输入框正在处理斜杠命令或发送时不写，弹层里会说明没有写入。
- 点一行右侧的「编辑」后，标题和正文展开在这一条下面。新建、删除和保存都在弹层里。未保存的数量用红字标在保存按钮旁。
- 设置 → 个人 → 提示词：同一份列表和正文。保存按钮在面包屑那一行，这一页不能写入输入框。

关掉弹层不会丢掉还没保存的修改，刷新页面会丢掉。保存时如果库刚被另一处改过，会拒绝覆盖，需要重新读取后再存。

## 存在哪里

Host 在当前 profile 目录读写 `prompt-library.json`，不进仓库。浏览器走已登录的 `GET` / `POST /api/prompt.library`。文件带整数版本号，保存必须带上打开时的版本号。

没有这个文件时，库是空的，版本号为 0。文件存在但内容不是一份库时，接口报无法读取，不会把它覆盖成空库。

一条提示词只有 `id`、`title`、`body`。最多 200 条，标题去掉两端空白后 1–200 字，正文最长 100000 字。`id` 只含字母、数字、下划线和连字符。

## 限制

- 不分组，也不能调整顺序。
- 弹层和设置页共享这一次打开里的未保存修改；真正落盘只发生在保存。
- 替换文件时先写临时文件再改名。Windows 上若目标已存在，会先删掉旧文件再改名，这中间进程退出可能留下临时文件或丢掉这一次写入。

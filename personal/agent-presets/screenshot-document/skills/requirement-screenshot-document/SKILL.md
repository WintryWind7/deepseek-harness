# 对照需求的截图文档

## 适用边界

本 Skill 只用于一种文档：**以需求条款为轴的截图文档**。

```text
需求原文（▲ 条款）
└─ 1-功能名-标注.png
└─ 1-功能名-标注.png
需求原文（▲ 条款）
└─ 6-功能名-标注.png
```

- 组织轴是**需求条款**，不是角色，也不是导航模块；图名带条款号（`1-` 对应 ▲（1），`6-` 对应 ▲（6））。
- 一条需求配一到多张图；图直接放在该条下面，一张一行。
- 判据：文档回答「这条需求有没有对应界面、界面长什么样」，而不是「这个角色怎么一步步操作」。

以下情况**不要**用本 Skill：

- 按角色和导航大模块组织的产品说明书、操作手册、学生实验指导书 → 用 `screenshot-document-authoring` 规划、`screenshot-document-writing` 写正文；
- 只要采一张脱离文档结构的独立图片，或只修某张图的标注 → 用 `real-web-screenshot`；
- 只导出 DOCX、只评审已有正文 → 不加载本 Skill。

### 与预设内旧规则的分歧（先读这段）

`screenshot-document-authoring` 与 `real-web-screenshot` 写的是「**页标题默认不框**」。本 Skill 覆盖的文档类型下结论相反：

```text
本类型：红框上沿必须把该屏的页面级主标题框进去
```

依据是同一批图的三次返工：主标 14 张重画、副标1 8 张重画、副标2 8 张重画，返工的核心都是「标题露在框外」。评审判据是「读者只看红框内的内容就能认出这是哪个页面」；标题不在框里就答不出来。

按标题的层级区分适用：

- 页面级**主标题**（模块名/页面名，如「学习任务管理」「我的学习任务」）：本类型**必须框进红框**；
- 卡片标题、表格列名、字段标签这类**内容局部标题**：随其内容一起被框，不单独画框；
- 弹窗、抽屉自身的标题带：随浮层内容一起框，见「红框怎么框」。

读到「页标题默认不框」时：当前任务是对照需求条款出图，以本 Skill 为准；是产品说明书或操作手册，以 `screenshot-document-authoring` 为准。规则冲突时，以用户本次明确要求为最高优先级。

## 从需求里挑条目

只收**句尾标明要截图**的需求。句尾是「提供平台功能界面截图」「提供软件界面截图」「提供功能界面截图」「提供软件界面功能截图并加盖公章」这一类的，整句收下。

句尾标明要**演示视频**的，不收进这份文档。同一句既要求截图又要求视频时，截图部分照收，视频另做。

原文**逐字抄**。编号、▲、括号和句尾的「提供…截图」都留着，不改字、不加解释、不补标点。

```text
## 系统名

▲（1）需求原文全句，到（提供…截图）为止。

![功能名](1-功能名-标注.png)

▲（6）需求原文全句，到（提供…截图）为止。

![功能名](6-功能名-标注.png)
```

需求原句里出现「教师」「学员」等角色时，先记下角色，用来决定后面要不要补角色视角的图（见「学生端补齐规则」）。

## 截图怎么截

```text
视口   1920 × 900
像素   1:1，不缩放
整屏   只截当前视口，不拼整页长图，不裁切、不拼接
```

- 同一个项目的所有图用同一个口径；不同标段之间也要一致，否则并排看得出差别，会被要求整套重截。
- 整屏截图保留浏览器真实观感，不要为了「适配比例」做拉伸、缩放或裁掉导航区。`1920×900` 是基准，不要强行改成其它比例。
- 用真实浏览器预览真实系统的真实页面，不要用设计稿、手绘界面或模拟数据代替。

### 标注画进 PNG 像素，不在浏览器里叠层

红框、箭头、红字在标注阶段直接画进 PNG 像素，不要在页面里加覆盖层再截。

原因：覆盖层受页面 CSS、滚动和状态影响，同一段代码两次跑可能不一样；画进像素后可以逐像素核验——框线 4px、主色 217/51/51 就是这么量出来的。

## 红框怎么框

### 上沿必须把页面级主标题框进去

框上沿落在该屏主标题带**之上**，让主标题完整落在框内。样本实测：

| 标段 | 页面标题带 | 框顶实测 |
|---|---|---|
| 主标 | y 104..126 | 90 |
| 副标1 | `.page-head` 72..106 | 66 |
| 副标2 | h2 107..140 | 76 |

**量法**（换项目要重新量，不要照抄上表数值）：

1. 先在**无标注**的底图上量出该屏主标题带的上下边界（页面头部容器、`h1`/`h2`、卡片标题）；
2. 框顶 = 标题带顶 − 6 px；
3. 复核：4 px 的框线落在标题文字上方，标题完整在框内、不被框线压到。

反例：主标早期的主内容框顶取的是 217，落在标题带之下，标题露在框外，被要求重画——这是最费事的一类错。

### 框内只放完整内容，下沿不切卡片

- 框内必须是**完整**的条目/卡片/表格行，不许可半张卡片。
- 下一张卡片只被视口露出一部分时，框下沿停在两张卡片的**空隙**里，不要切卡片。
- 也可以把下沿延到该卡片的底边，把最后一张可见卡片纳完整（样本里两种做法都用过：一种停在 12 px 空隙，一种把下沿从 733 延到 898 纳完第 4 张任务卡）。选哪取决于哪种能让框内内容更完整、更好解释。
- 框不得超出视口。若标题与后面内容隔了很长的滚动内容、无法同框，**只框标题那一屏**，不要为了凑内容把框拉出视口。
- 框下沿紧贴卡片底边时要留一点余量，不要把卡片阴影、分隔线切一半。

### 弹窗、抽屉

- 框贴齐浮层内的有效内容并留内边距，不要只贴容器外边，也不要把背后被遮罩的页面并进同一个框。
- 浮层遮住页面时，红字仍按「红字怎么写」的规则放到框外空白处（通常是弹窗上方的空白带），不要因为空间紧就贴到框内或压住被遮罩的页面。

## 红字怎么写

### 放在框外的画面空白处

优先顺序：**框顶上方留白带 → 框左侧留白**。

框顶上方没有留白（框紧贴页头）时，退到框左侧，这是允许的退让，不是例外。

**不留框下方**：框下方紧邻下一行正文或下一张卡片，很容易压到内容；而且同一屏的排法要在各标段之间保持一致，同一份需求下的图左右跳会显得杂乱。

选定位置后必须做**禁压检查**：不许压到任何 UI 元素、正文、其它标注文字、任何框线。

### 先量禁压区与留白带

```text
通用     : 面包屑、日期、用户信息区、右上角图标区、左侧导航栏、主内容区
主标顶栏 : 面包屑 (254,25,333,46)、日期 (1494,26,1600,45)、用户信息 (1671,16,1848,55)
           主内容区 (228,72,1920,900)、导航栏 (0,0,228,900)
副标1学员顶栏：brand (18,12,202,40)、nav (220,8,819,43)、topbar-right (1677,13,1902,38)
           可用留白带 x 819..1677
```

量法：在底图上量出顶栏各元素与侧栏的矩形，两者之间的空白就是可用留白带；红字矩形（含行高）必须完全落在留白带内。

真实约束举例：主标的红字挤在顶栏中段的空白带；副标1 学员顶栏只有 52 px 高，只能靠量出的留白带避让，否则压住系统名或导航。

字数越多，可用留白带越紧张。字放不下时先精简文案（见下），不要为了塞字去压元素。

### 句式与文案来源

句式统一为「**模块名，可……**」，模块名取该屏页面主标题：

```text
学习任务管理，可管理已发布学习任务
班级管理，可查看班次、班主任及学员人数
课程管理，可查看课程名称、学时、教学次数
```

### 文案必须与本屏画面字段逐字对上

写之前逐条对照**这一屏**截图里的列名、卡片名、标签名，不能跨标段/跨项目复制文案：

```text
对    : 班级管理，可查看班次、班主任及学员人数      （该屏画面列名如此）
对    : 课程管理，可查看课程名称、学时、教学次数    （该屏画面列名如此）
错    : 班级管理，可查看在线班级、教师及学生人数    （照抄别的标段，与本屏画面不符）
错    : 课程管理，可查看课程名称、学时、题目数量    （同上）
```

同一句模板在不同系统里要按各自画面改。出现过照抄别的标段文案、与画面列名不符被要求改的情况。

- 文字末尾**不加句号**，各条保持一致。
- 不用「首页内容」「相关内容」「此处显示信息」这类无法说明框内内容的泛称。
- 说明操作时用「动词 + 对象」，如「点击新建考试」「查看考试结果」。

## 箭头怎么画

一根直线，从文字边缘出发指向红框边框：

- 可见长度 ≥ 48 px；不足时沿原方向延长到 48 px，可以把终点伸进框内补足长度，不要把文字拉远；
- 两端分别落在文字块边界与框边界的**投影交点**上，不悬空、不越过框另一侧的框线；
- 不指向框的四个角（离角至少 16 px，端点贴角要退让）；
- 不穿过其它标注文字、其它框线或框内内容；
- 水平、垂直或自然斜向都可以，但必须是一条**单段直线**，不要折线、曲线或多次转弯。

出现过箭头过短、指向角上、被旁边文字压住，导致指代不清。

## 标注常量（照抄）

```text
红     = (217, 51, 51)          # #D93333
框线宽 = 4 px（空心矩形 outline，不填充）
箭头   = 单根直线，宽 5 px；箭头头部 长 16、半宽 8；可见长度 ≥ 48 px
字号   = 25 px，字体 msyh.ttc（微软雅黑）
行高   = 33 px（多行文字）
间隙   = 文字在框上方时距框 12 px；在框左侧时距框 36 px
画布   = 1920 × 900，标注不得超出（四周留 4 px）
```

这是三个标段最后收敛到的同一套值：成品实测框线厚度全部 = 4、主色全部 = 217/51/51。箭头 ≥ 48px 是因为出现过短箭头看不清指向——48 px 是最低可读长度，不是统一目标长度，满足避让后选最短自然位置。

标注文字不绘制背景、边框、色块、圆角或阴影；默认不加序号，只有同图表达连续步骤或用户明确要求时才加。

## 学生端补齐规则

**需求原句里出现的每个角色，都要有该角色视角的截图。**

```text
▲（1）「教师可以发布每次培训的学习任务以及考核任务等」      → 教师端
▲（6）「培训教师和学员可以在日历表上查看……」              → 教师端 和 学员端
```

只要原句出现「学员可以…」「培训教师和学员…」这类表述，就必须补学员端截图，不能只给教师端。样本里三个标段各补了 2 张：

| 标段 | 新增 | 张数变化 |
|---|---|---|
| 主标 | `1-学员学习任务`、`6-学员成绩` | 14 → 16 |
| 副标1 | `1-学员培训考核`、`6-学员答题` | 8 → 10 |
| 副标2 | `1-学员学习任务`、`6-学员开始答题` | 8 → 10 |

学员端同样「红框含页标题 + 红字放顶栏留白带」，且只标主内容，不放导航入口框。补图后要同步更新那份 md 的图数与交付物。

## 图的命名与编号

- 一个标段（一份文档）对应一份 `截图.md`，这份 md 就是该标段的清单。
- 图名：`<条款号>-<功能名>-标注.png`，条款号 `1`／`6` 对应 ▲（1）／▲（6）。
- 功能名用画面上的真实业务名，不用内部名、路由名、组件名。
- 图放到对应条款下面，一张一行；▲ 原句逐字抄。
- 图与上下文字之间空一行；一条需求下多张图时连续排列。

## 自检清单

```text
[ ] 只收了句尾标明要截图的需求；要演示视频的没收
[ ] ▲ 原句逐字未改，编号与括号保留
[ ] 需求里出现的每个角色（教师/学员）都有对应截图
[ ] 每张图尺寸恰好 1920×900，整屏、未裁切、未拼页
[ ] 该屏页面级主标题带已量出坐标，框顶取标题带顶 − 6px
[ ] 红框上沿在页面主标题之上，标题完整在框内、未被框线压到
[ ] 框内没有半张卡片；下沿停在卡片空隙或完整卡片底
[ ] 框没有超出视口
[ ] 红字在框外空白处，不压顶栏/侧栏/用户区/正文/其它文字/框线
[ ] 红字优先在框顶上方；无留白时退框左侧；没有放到框下方
[ ] 箭头单根直线、宽 5、可见长度 ≥ 48px、指向框边不指角、不穿别的文字
[ ] 颜色 217/51/51、框线 4px、字号 25、行高 33、间隙 上方 12／左侧 36
[ ] 文案与该屏画面字段逐字对得上，句式「模块名，可……」，末尾无句号
[ ] 图名带条款号，md 里每条需求的图都能在目录里找到
[ ] 逐张用图像读取工具看过最终图，未读图不声称标注正确
```

## 已知坑

| 现象 | 原因 | 正确做法 |
|---|---|---|
| 页面主标题露在红框外，被要求返工 | 框顶取在标题带下方（早期取 217，标题带 104..126） | 框顶取标题带顶 − 6px（样本：90／66／76） |
| 红框把第 4 张任务卡切一半 | 框下沿按「大概高度」写死（733） | 下沿取完整卡片底或卡片间空隙（样本改成 898） |
| 下一张卡被视口截断，框切到卡片 | 想同时纳入标题和后面内容 | 只框当前屏；下沿停在空隙（样本停在 12px 空隙） |
| 红字压住面包屑/日期/用户区/导航 | 凭感觉放文字 | 先量禁压矩形与留白带；主标留白在顶栏中段，学员顶栏留白 x 819..1677 |
| 红字放在红框下方，或贴着侧栏文字 | 习惯把字放在框下方或紧贴侧栏，没有先量留白区 | 文字必须落在框外空白处：优先框顶上方；无留白退框左侧，不留框下方 |
| 文案与画面不一致：写「题目数量」而画面列名是「教学次数」，末尾还多一个「。」 | 套用别的标段文案，没有逐条核对本屏列名；末尾标点没统一 | 按**本屏画面**逐条核对列名与卡片名，句式统一「模块名，可……」，末尾不加句号 |
| 各标段图并排看着不一样 | 视口不统一（有的用 1440×1020） | 一律 1920×900 整屏、1:1 不缩放 |
| 箭头太短、指向框角或被旁边文字压住 | 起终点按感觉取，没有按文字边界与框边投影交点算 | 单段直线、可见 ≥48px、离角 ≥16px、不穿其它文字 |

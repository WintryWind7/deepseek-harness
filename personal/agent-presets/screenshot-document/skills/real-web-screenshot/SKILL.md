# 真实网页截图与标注

## 目标与边界

本 Skill 负责驱动真实网页进入指定状态，采集清晰截图，并生成可用于 Markdown 文档、DOCX、培训材料、测试报告、需求说明和演示材料的标注图。

默认流程：

```text
接收调用方给出的单图或批量截图执行规格
→ 调查源码和真实页面
→ 打开真实网页并进入指定状态
→ 按指定范围截取原始图
→ 按指定标注意图绘制目标框、文字和箭头
→ 逐图读图核对
→ 返回原始图、标注图和实际检查结果
```

本 Skill 只负责把已经定义好的截图要求准确实现，不负责决定文档按什么角色、导航或章节组织，也不负责决定一个模块需要截哪些图。截图文档的图片规划由 `screenshot-document-authoring` Skill 负责；Markdown 正文和 DOCX 转换由调用方或其它 Skill 负责。

禁止：

- 修改业务代码、测试、配置或数据库结构；
- 为清理、探查额外功能或其它与当前截图目标无关的目的创建、保存、发布、冻结、删除、撤回、导入、重置或提交业务数据；
- 使用虚构页面、手绘界面、设计稿或模拟截图代替真实系统画面；
- 为了让截图更好看而篡改页面内容或隐藏真实问题；
- 把账号、密码、令牌或认证状态写入源码、文档或可提交文件；
- 自动把未经核对的截图插入正式文档。

## 截图执行规格

调用方应为每张图片提供明确的执行规格。截图 Skill 可以通过源码和真实页面补全技术细节，但不得自行改变文档结构和图片目的。

每张图至少需要：

| 字段 | 含义 |
|---|---|
| 图片编号和输出路径 | 原始图写入 `origin/`，标注图写入 `annotated/` |
| 目标角色和认证上下文 | 使用哪个真实角色进入系统 |
| 目标页面状态 | 截图时必须真实出现什么 |
| 保留区域 | 完整 1920 × 900 视口，或从该视口切出的完整主页面边界 |
| 标注意图 | 需要框选什么以及标注文字 |
| 必须生成标注图 | 文档截图通常为“是”；为“是”时不得只输出原始图 |
| 序号 | 是否添加 ①、②、③ |
| 预期业务状态变化 | 为达到截图状态预计会发生什么变化 |

如果执行规格缺少以下关键信息且无法通过调查补全，返回调用方修正规格或向用户确认：

- 无法确定目标页面状态；
- 无法确定保留区域；
- 标注意图对应多个不同目标；
- 缺少只能由用户提供的认证信息。

批量任务按调用方给出的顺序执行，不擅自增加、删除、合并或重排图片。

执行规格标记“必须生成标注图”时：

- 每项标注意图都必须生成对应的目标框、标注文字和直达箭头；
- 不得因为页面拥挤、布局困难或调用方没有再次强调，就跳过全部或部分标注；
- 无法安全放置某项标注时，返回具体冲突并要求调整规格，不能静默输出未标注图片；
- 原始图必须保留在 `origin/`，并写入对应 `.origin.json`，但不能替代最终标注图；
- 完成后逐项对照执行规格检查标注数量、目标、文字和箭头。

## 标注概念

一项完整标注由目标、目标框、标注文字、箭头和可选序号组成。

### 目标

目标是需要读者关注的真实页面控件或内容区域，例如：

- 导航菜单；
- 按钮；
- 页签；
- 筛选区域；
- 表单填写区；
- 表格；
- 结果卡片；
- 详情内容区。

### 目标框

目标框是绘制在目标外围的红色矩形框，也可简称“红框”。目标框只绘制红色轮廓，不填充内部颜色，不用半透明遮罩覆盖真实页面内容。

先区分裁剪范围和标注目标：

- **主页面**是导航栏以外的整块面板，内容图切出的就是它；一般不把整块主页面画成一个目标框。
- **主内容**是主页面里当前要说明的工作区；这是概念，不是固定矩形，同屏可以有多块。默认在主内容内部框选，能合并就合并。
- **页标题**默认不框。
- **独立按钮**离当前主内容较远时单独框，不要为了并进去而扩成整块主页面。
- **抽屉、弹窗**打开后，当前主内容改到浮层内部：框贴齐浮层里的有效内容并留内边距，不要只贴容器外边，也不要把背后被遮罩的主页面并进同一个框。

框选具体操作时，框住控件本身，例如菜单项、按钮或页签。说明一个功能区域时，红框必须覆盖该状态下实际可见、能证明标注文案的内容，例如已显示的卡片组、表格行、结果区域、表单区或明确空状态；不得只框页标题、表头或标签。

不得把大面积空白的布局父容器当作列表、表格或结果区域。列表文案只能指向真实可见的列表内容；若页面没有内容，先达到有数据的真实状态，或按实际空状态标注，不能给空白容器贴“列表”标签。截图仍保留完整主页面上下文，但红框只框实际有意义的目标范围。

不得无理由框选整块主页面或大面积背景。只有用户明确要求标整块主页面、或当前操作面几乎铺满主页面时，才允许使用接近主页面的大框。

默认把同一块主内容收成一个框。只有两个动作会走出不同路径、或独立按钮离主内容明显较远时才拆框，且动作框只框按钮本身。同屏重复出现同类组件、字段或入口而执行规格没有比较目的时，只框计划指定的代表实例；不得因页面上有多个相同实例就重复绘制相同的目标框、文字和箭头。执行规格明确要求比较不同实例、状态或结果时，才分别标注多个实例。

### 标注文字

标注文字是直接绘制在截图上的红色短文字或一至两句简短说明，用于说明目标是什么、展示哪些具体信息、具有什么功能或需要执行什么操作。

标注文字默认：

- 不绘制背景；
- 不绘制可见边框；
- 不绘制色块、圆角卡片或阴影；
- 不自动添加序号；
- 使用红色文字；
- 放置在目标附近；
- 不得与任一目标框的边框线相交；
- 不得遮挡该框所要说明的实际内容；
- 目标框内外的普通页面内容不属于强制避让区域；附近有自然空白时优先使用，没有合适空白时允许文字直接覆盖框内空白区和框外未框选内容，绝不能为了避让这些内容而把文字放到距离目标很远的位置。

标注文案必须由红框内图中真实可见的内容证明。导航菜单写“真实菜单名称 + 入口”；页面内容除业务名称、对象或状态外，可以用一至两句简短说明交代实际展示的信息、功能或用途，例如：

```text
班级管理入口
课程资源入口
考试管理入口
```

页面内容可以写实际对象、状态或红框内可见信息的简短说明，例如：

```text
班级卡片
考试列表
筛选条件
暂无课程
首页展示学习进度、待完成任务和课程入口
```

“列表”“结果区域”等名称必须与红框中的实际可见内容一致；没有可见内容时使用真实空状态，不能给空白布局容器命名。

说明操作时，使用“动词 + 对象”：

```text
点击新建考试
选择考试试卷
查看考试结果
填写考试名称
```

不得使用无法说明红框实际内容的泛称：

```text
首页内容
这里是操作区域
相关内容
根据情况操作
此处显示信息
```

跨页面、跨状态的完整教程和长段背景解释仍属于 Markdown 正文，不得塞进截图标注。

### 文字边界

程序必须计算标注文字实际占用的矩形边界，用于：

- 确定箭头起点；
- 避免箭头穿过文字；
- 防止文字超出画布；
- 检查是否与目标框边框线相交、是否遮挡框内内容，以及是否与其它标注文字重叠。

文字边界仅用于内部计算，不得绘制为可见背景框或边框。文字边界不得与任一目标框的边框线相交，也不得遮挡任一目标框所要说明的实际内容，包括自身关联目标和其它标注项的目标；也不得与其它标注文字重叠。文字可以落在目标框内或框外的空白处，不要求位于框外。任一检查失败时必须重新选择文字位置，不能通过调整箭头掩盖问题。

标注文字位置按以下优先级选择：

1. 文字边界位于画布内，不与任一目标框的边框线相交，不遮挡任一目标框所要说明的实际内容，也不与其它标注文字重叠；
2. 文字到自身目标的箭头可见线段达到最短长度；
3. 目标附近恰好有自然空白时优先使用；
4. 附近没有合适空白时，允许文字覆盖目标框内外的普通页面内容；
5. 在满足前四项的候选位置中，选择距离自身目标最近、箭头最短且自然的一处，不得为了避让无关页面内容把文字移得过远。

### 可选序号

序号不是默认元素。

以下情况默认不添加序号：

- 区域说明；
- 单个目标；
- 没有明确操作顺序；
- 用户提供的视觉示例没有序号且未要求添加。

同一张图需要表达连续步骤，或者用户明确要求编号时，可以使用：

```text
① ② ③
```

序号直接作为标注文字的一部分绘制，仍然没有背景框。

### 箭头

箭头连接标注文字和目标框。

默认且必须使用红色单段直达直线箭头：

```text
红色标注文字 ───► 红色目标框
```

“直达”表示箭头从标注文字边缘到目标框之间只能有一条直线段。箭头可以根据文字和目标的相对位置自然地水平、垂直或斜向连接，不要求固定为 0、90 或 180 度，也不应为了追求水平垂直而把文字放到不自然的位置。

绝对禁止：

- 直角折线；
- 两段或多段路径；
- 连续转弯；
- 曲线和弧线；
- 为绕开页面内容而画出歪歪扭扭的路径；
- 使用多个短线段拼成看似直线的箭头。

箭头起点必须位于标注文字不可见边界朝向目标的一侧，终点至少到达目标框边缘，也可以继续伸入框内。终点必须落在某一条边的中段，不得指向或贴住目标框的四个角；斜向连接时沿最近的边滑开，不要停在角上。禁止让箭头从文字中心穿过文字，也不得无理由指向目标框中心。

以 `1920 × 900` 完整视口为基准，箭头可见线段的总长度不得短于 48 像素，其中终点至少到达目标框边缘，可以继续伸入框内补足长度。48 像素是最低可读长度，不是统一目标长度：文字位置先满足所有目标框和文字的避让，再在合格候选中选择距离目标最近、箭头最短且自然的位置。文字离目标框很近时伸入框内补足，不为了凑长度把文字移到远处。

直达箭头可以经过所有目标框之外的普通页面内容，以及自身目标框内部，不为这些内容绕路。如果直线会穿过其它标注文字、其它目标框或其框内内容，或者没有同时满足避让和最短长度的文字位置，只能在目标附近调整文字位置、加深箭头伸入自身框内的距离、选择目标框的另一侧边缘，或减少同一张图的标注数量。不能把箭头改成折线、曲线或多次转弯路径，也不能为了满足长度把文字移到不自然的远处。

### 原始截图与标注截图

- 原始截图：未添加目标框、标注文字、箭头和序号的真实网页截图；
- 标注截图：在原始截图上添加标注元素后生成的图片。

每张标注截图默认保留对应原始截图，避免标注调整时重新执行网页操作。

## 真实页面探查

### 先在真实浏览器确认可达，再按需查源码

最终截图必须由目标角色在真实前端中可达到：从登录后的实际入口出发，使用可见的导航、菜单、按钮、页签、卡片或详情入口逐步进入目标页面。不得通过直接输入内部路由地址或依据源码找到的路由绕过前端入口，再把页面作为角色入口或操作结果的截图。

目标入口不存在、无法点击、点击后没有进入预期页面，或当前角色没有权限时，停止当前图片的采集，向用户报告实际角色、入口、操作、页面结果和影响；不得改用直接 URL、其它角色或未说明的替代路径继续截图。源码不能代替真实前端可达性。

浏览器探索无法确定入口、按钮含义、权限表现、写操作影响、异步结果或稳定选择器时，再查源码寻找线索。可按需定位：

```text
角色菜单和页面组件
按钮、页签和弹窗标题
点击事件与跳转结果
保存、发布、删除和提交方法
异步请求结束后的结果元素
权限和数据范围判断
```

不要假设按钮、页签或导航名称。源码只提供线索，最终以真实浏览器中的可达路径和显示结果为准。

### 在真实浏览器中探查

执行正式自动化操作前：

1. 以目标角色登录，并从当前真实前端入口开始；
2. 逐步操作可见入口，确认每一步真实可点击且页面跳转或状态变化正确；
3. 获取目标页面真实文字、按钮、链接、页签或初步截图，并根据结果编写稳定选择器；
4. 每次状态改变后确认目标元素已经真实出现。

探查示例：

```python
print(page.locator("body").inner_text())
print(page.get_by_role("button").all_inner_texts())
```

## 浏览器和截图标准

本机网页优先使用 Python Playwright 和系统 Chrome，无头运行，不得弹出可见浏览器或终端窗口。

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(
        channel="chrome",
        headless=True,
    )
    page = browser.new_page(
        viewport={"width": 1920, "height": 900},
        device_scale_factor=1,
    )
```

系统 Chrome 的位置必须先调查，不得只假设一个固定用户目录路径。只有运行环境已确认时才使用明确的 `executable_path`。

统一截图基准：

```text
viewport：1920 × 900
device_scale_factor：1
full_page：false
```

截图前：

```python
def shot(page, output_path):
    page.evaluate("window.scrollTo(0, 0)")
    page.wait_for_timeout(300)
    page.screenshot(path=str(output_path), full_page=False)
```

固定等待只能用于页面已经确认完成后的短暂视觉稳定，不得代替最终状态检查。

文档截图必须先生成一张 `1920 × 900`、`full_page=false` 的完整视口原始图，再根据执行规格决定是否保留完整视口或切出主页面。不得直接对按钮、表格、弹窗、结果卡片或其它标注目标执行元素截图。

需要排除导航栏时，从完整 `1920 × 900` 原始图按导航栏与主页面的真实布局边界裁剪：

- 左侧导航：主页面裁剪框为 `(nav_right, 0, 1920, 900)`；
- 顶部导航：主页面裁剪框为 `(0, nav_bottom, 1920, 900)`；
- 其它布局：导航区和主页面的边界必须共同覆盖完整视口，不重叠、不留缝。

DOM 和布局容器只用于确认导航与主页面的切分边界，不能用来把标注目标单独截成小图。调用方要求多张内容图复用一致区域时，应复用同一切分边界，除非页面整体布局本身发生变化。

裁剪只允许删除导航区域，不允许拉伸、压缩、缩放、补白或重新排版。左侧导航宽度加内容图宽度必须等于 1920；顶部导航高度加内容图高度必须等于 900。切分后的内容图保持原始像素比例和自然尺寸，不再放大回 `1920 × 900`。

目标框属于标注层，不属于裁剪边界。先得到完整主页面大图，再在大图中画目标框、文字和箭头；即使目标只是一个很小的按钮，也绝对不能把最终截图裁成按钮或目标框大小。默认 25 像素标注字号按裁剪前后的原始像素绘制，不因为裁剪而自动变小。

## 等待最终状态

禁止在异步页面仍处于中间状态时截图。根据目标等待真实结果元素：

```python
page.wait_for_load_state("networkidle")
page.locator("tbody tr").first.wait_for(timeout=15000)
page.locator(".result-card").first.wait_for(timeout=15000)
page.get_by_role("dialog").wait_for(timeout=15000)
```

截图不得包含：

```text
Loading / 加载中
骨架屏
空白内容区
错误提示页
页面跳转中的闪烁状态
未展开的目标区域
与目标角色不符的页面
```

## 控件定位优先级

按以下优先级定位，只有前一种不可用时才使用后一种：

```text
1. get_by_role
2. get_by_text(..., exact=True)
3. get_by_label / get_by_placeholder
4. data-testid 或稳定 CSS
5. 坐标点击
```

示例：

```python
page.get_by_role("button", name="新建考试", exact=True).click()
page.get_by_text("管理考试", exact=True).first.click()
page.get_by_role("tab", name="考试规则", exact=True).click()
```

坐标点击只能用于布局已确认固定且不存在稳定语义选择器的情况，不可作为常规定位手段。

### 可滚动导航栏

执行规格要求标注导航入口时，先定位实际需要点击的目标菜单项。导航栏有独立滚动容器时，应滚动导航容器或对目标项调用 `scroll_into_view_if_needed()`，不能只滚动整个页面：

```python
nav_item = page.get_by_text("课程资源", exact=True)
nav_item.scroll_into_view_if_needed()
nav_item.wait_for(state="visible")
```

截图前确认：

- 目标菜单项完整位于导航可视区域内，没有上下或左右裁切；
- 菜单项当前真实可点击；
- 需要展开的上级菜单已经展开；
- 目标框坐标来自实际目标菜单项可点击区域；
- 不把整个导航栏、上级菜单组或相邻菜单作为目标框替代品。

## 页面状态与保留区域

调用方决定图片需要表达的页面状态和保留区域，本 Skill 负责在真实网页中准确达到并截取。

保留区域可以是：

```text
完整 1920 × 900 页面视口
从完整视口切出的完整主页面
```

不得把稳定 DOM 内容容器或标注目标元素本身直接当作最终截图范围。DOM 只用于确定导航与主页面边界，以及取得目标框坐标。

模块内容图从完整视口切出主页面后，必须保留主页面中当前可见的全部上下文。不得围绕目标框再次二次裁剪，也不得切掉与该页面同屏显示的页标题、页签、工具栏、弹窗、表格、表单、留白或结果区域。

同一批图片要求使用一致保留区域时，应复用相同导航与主页面切分边界。截图 Skill 不自行判断某张图是否应该包含导航栏，这由调用方提供的执行规格决定。

如果一张图的标注意图过多，无法在不遮挡目标的情况下清楚完成，应返回调用方拆分图片，不擅自缩小字号、删除标注或改变文档结构。

### 尺寸缩放

标注坐标以 `1920 × 900` 为基准。图片尺寸不同时按比例缩放：

```python
def scaled(rect, sx, sy):
    return tuple(
        round(v * (sx if i % 2 == 0 else sy))
        for i, v in enumerate(rect)
    )
```

### 目标框边缘点

```python
CORNER_INSET = 16

def point_on_rect(rect, point):
    x1, y1, x2, y2 = rect
    px, py = point
    return min(max(px, x1), x2), min(max(py, y1), y2)

def avoid_rect_corner(rect, point):
    x1, y1, x2, y2 = rect
    px, py = point
    inset_x = min(CORNER_INSET, max((x2 - x1) / 4, 1))
    inset_y = min(CORNER_INSET, max((y2 - y1) / 4, 1))
    on_left = abs(px - x1) <= 1
    on_right = abs(px - x2) <= 1
    on_top = abs(py - y1) <= 1
    on_bottom = abs(py - y2) <= 1
    if (on_left or on_right) and (on_top or on_bottom):
        # 角上：沿更长的邻边滑到中段，不要把箭头尖停在角上。
        if (x2 - x1) >= (y2 - y1):
            py = min(max(py, y1 + inset_y), y2 - inset_y)
        else:
            px = min(max(px, x1 + inset_x), x2 - inset_x)
    elif on_left or on_right:
        py = min(max(py, y1 + inset_y), y2 - inset_y)
    elif on_top or on_bottom:
        px = min(max(px, x1 + inset_x), x2 - inset_x)
    return px, py
```

### 箭头从不可见文字边界出发

```python
MIN_ARROW_LENGTH = 48

# 先从目标四周生成文字候选位置。仅保留同时满足以下条件的位置：
# - 文字边界在画布内；
# - 文字边界不与 all_target_rects 中任一目标框的边框线相交，也不遮挡其要说明的内容；
# - 文字边界不与其它标注文字相交；
# - 连线不穿过其它文字或非自身目标框。
# 在合格候选中选择距自身目标最近的一项。
text_rect = selected_text_rect
text_center = (
    (text_rect[0] + text_rect[2]) / 2,
    (text_rect[1] + text_rect[3]) / 2,
)
# 终点至少落在目标框边缘中段，不得落在四个角上；到框边不足 48 px 时沿同一方向伸入框内补足整段长度。
edge = avoid_rect_corner(target_rect, point_on_rect(target_rect, text_center))
arrow_start = point_on_rect(text_rect, edge)
dx, dy = edge[0] - arrow_start[0], edge[1] - arrow_start[1]
span = max((dx * dx + dy * dy) ** 0.5, 1)
reach = max(span, MIN_ARROW_LENGTH)
target = (arrow_start[0] + dx / span * reach, arrow_start[1] + dy / span * reach)
draw_arrow(draw, arrow_start, target, RED)
```

视觉目标：

```text
红色标注文字边缘 ───► 目标框某一条边的中段或继续伸入框内（整段不少于 48 px）
```

不能是：

```text
红色箭头穿过标注文字 ───► 目标框中心
红色箭头 ───► 目标框的角
```

### 直线箭头绘制

```python
def draw_arrow(draw, start, end, color):
    draw.line([start, end], fill=color, width=5)
    dx, dy = end[0] - start[0], end[1] - start[1]
    length = max((dx * dx + dy * dy) ** 0.5, 1)
    ux, uy = dx / length, dy / length
    px, py = -uy, ux
    left = (end[0] - ux * 16 + px * 8, end[1] - uy * 16 + py * 8)
    right = (end[0] - ux * 16 - px * 8, end[1] - uy * 16 - py * 8)
    draw.polygon([end, left, right], fill=color)
```

## 偏移、遮挡和反馈修正

用户反馈“歪了一点”“箭头压住文字”“目标框太大”“页面不对”时先分类，不得机械移动全部标注。

| 问题表现 | 正确处理 |
|---|---|
| 页面状态不对 | 重做网页操作并重新截图 |
| 目标控件没有出现 | 回查源码、权限和前置操作 |
| 红框位置偏移 | 调整目标框坐标 |
| 红框只框页标题 | 改框该标题对应的主内容，页标题本身默认不框 |
| 红框包住整块主页面 | 收到主内容；远距按钮单独框，不要为了合并而扩回主页面 |
| 抽屉或弹窗只框容器外边 | 收到浮层内有效内容并留内边距，不要把背后被遮罩的主页面并进同一个框 |
| 标注文字压住任一目标框的边框线，或遮住该框要说明的内容 | 必须移动文字，压线和遮挡都不允许 |
| 标注文字覆盖框内空白区或框外的普通页面内容 | 可以接受；若移动会使文字离目标更远，则保持当前位置 |
| 标注文字离目标过远 | 移回目标附近，允许覆盖普通页面内容；整段箭头仍须不少于 48 px |
| 箭头短于 48 px | 沿指向目标的方向伸入框内补足长度；若会遮住框内内容，再微调文字位置或拆分标注 |
| 多段文字互相重叠 | 分散位置或减少单图标注数量 |
| 箭头穿过文字 | 使用不可见文字边界计算起点 |
| 箭头出现折线、曲线或多次转弯 | 改为一条自然角度的直达直线 |
| 箭头穿过框内空白区或框外未框选内容 | 可以接受，不为其增加转弯或拉远文字 |
| 箭头穿过其它目标框、框内内容或其它标注文字 | 在目标附近调整文字位置或目标边缘终点 |
| 箭头指向或贴住目标框的角 | 把终点沿最近的边滑到中段，或改选另一条边 |
| 标注文案与页面不一致 | 回查源码和真实页面后修正文字 |

固定调整顺序：

```text
先确认页面状态
→ 调整目标框
→ 调整标注文字位置
→ 检查箭头起点和终点
→ 只重新生成这一张图片
→ 使用图像读取工具检查最终图
```

不得因为一张图偏移就重做全部图片。

## 输出目录和文件名

文档助手任务使用当前工作区的 `.dsh/screenshot-document/` 存放脚本、临时文件、原始图和标注图工作副本。本 Skill 不创建或修改 Markdown，也不把标注图写入 `assets/`。

```text
.dsh/screenshot-document/
├─ scripts/      Playwright、标注和其它可复用脚本
├─ temp/         当前任务一次性文件：storage state、认证缓存、标注坐标、参考图、调试截图、预览
├─ origin/角色/导航大模块/
│  ├─ 01-考试列表.png
│  └─ 01-考试列表.origin.json
└─ annotated/角色/导航大模块/
   └─ 01-考试列表-标注.png
```

调用方给出输出路径时严格使用该路径。未给出时，原始图默认写入 `origin/`，标注图默认写入 `annotated/`。不得使用仓库根目录的 `qa-tmp/` 或 `.dsh/qa-tmp/`，也不得把脚本、认证缓存、调试文件或标注图工作副本写入正式文档或 `assets/`。`.dsh/` 由 Git 忽略，这些文件禁止提交。Markdown 引用 `annotated/`、以及稍后复制到 `assets/`，由调用方或写作 Skill 处理。

原始图保存后必须立即写入同名 `.origin.json`，记录截图时的 Git 状态，供后续判断该原图是否还能直接复用：

```json
{
  "commit": "<git rev-parse HEAD 的完整 SHA，无法取得时为 null>",
  "branch": "<git branch --show-current，无法取得时为 null>",
  "dirty": true,
  "capturedAt": "2026-04-08T12:00:00+08:00",
  "unavailableReason": null
}
```

`dirty` 为 `git status --porcelain` 是否非空。不是 Git 仓库或无法取得 HEAD 时，`commit` 和 `branch` 写 `null`，并在 `unavailableReason` 写明原因，不得编造提交。

复用已有原图前，读取对应 `.origin.json`：

- `commit` 与当前 `HEAD` 相同，且当时 `dirty` 为 `false`、当前工作区也干净：可以只重新标注，不必重截；
- `commit` 不同、当时或现在 `dirty`，或缺少记录：不得直接当作当前页面原图，必须重新截取。

原始图和标注图应使用可对应的名称。原始图不带 `-标注` 后缀；标注图带 `-标注` 后缀并写入 `annotated/`：

```text
origin：01-考试列表.png
origin：01-考试列表.origin.json
annotated：01-考试列表-标注.png
origin：02-新建考试弹窗.png
origin：02-新建考试弹窗.origin.json
annotated：02-新建考试弹窗-标注.png
```

禁止使用：

- 临时随机文件名作为最终文件名；
- 浏览器缓存路径；
- 未经调用方指定的临时目录；
- 与执行规格不一致的文件名和路径；
- 把原始图、`.origin.json` 或标注图工作副本写入 `assets/`。
